# Radar stratégique cyber France

Démo Streamlit construite à partir du corpus public d'intelligence marché.

## Lancer localement

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## Déploiement Streamlit Community Cloud

1. Placez le contenu de ce dossier dans votre dépôt GitHub privé.
2. Dans Streamlit Community Cloud, choisissez ce dépôt et le fichier `app.py`.
3. Déployez, puis invitez votre cofondateur comme lecteur.
